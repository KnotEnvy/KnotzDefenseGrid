## sentinel-grid/

The first attempt at this game: a Python/Pygame tower-defense prototype ("Sentinel Grid"), inspired by
*Defense Grid: The Awakening*. It was replaced by **BEAMFALL** (the Phaser 4 game in the repository root),
which keeps the same genre DNA but starts from a clean architecture and an original Dark Tower story.

It was not touched when it was archived (apart from deleting committed `__pycache__` files). Entry point:
`sentinel-grid/main.py`, dependencies in `sentinel-grid/requirements.txt`, its own design notes in
`sentinel-grid/devDocs/`.
